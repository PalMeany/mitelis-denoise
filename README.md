# Mitelis Denoise

Убирает шумный фон из панели управления

## Установка

**Chrome / Edge / Brave / Vivaldi / Arc**

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `mitelis-denoise-main` (или как у вас называется распакованный архив). 

Chrome покажет предупреждение про неизвестный ключ `background.scripts` — этот ключ нужен Firefox, Chrome его игнорирует.

**Firefox**

1. `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение».
2. Выбрать файл `manifest.json`.

Временное дополнение живёт до перезапуска браузера. Для постоянной установки нужен подписанный `.xpi` (`web-ext sign` через addons.mozilla.org). Мне лень и похуй.
