# Mitelis Noise Killer

Скрывает шумовой оверлей (`div.noise.fixed.inset-0[aria-hidden="true"]`) на
`workspace.mitelis.net`. Клик по иконке в тулбаре — включить/выключить;
состояние сохраняется и применяется во всех открытых вкладках сразу, без
перезагрузки. Бейдж `OFF` на иконке означает, что скрытие выключено.

Расширение запрашивает единственное разрешение — `storage`. Доступа к каким-либо
сайтам, кроме `workspace.mitelis.net`, у него нет.

## Установка

**Chrome / Edge / Brave / Vivaldi / Arc**

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `mitelis-noise-killer`.

Chrome покажет предупреждение про неизвестный ключ `background.scripts` — так и
задумано, этот ключ нужен Firefox, Chrome его игнорирует.

**Firefox**

1. `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение».
2. Выбрать файл `manifest.json`.

Временное дополнение живёт до перезапуска браузера. Для постоянной установки
нужен подписанный `.xpi` (`web-ext sign` через addons.mozilla.org).

## Как это устроено

Скрытие сделано на CSS, а не удалением узла: `hide.css` инжектится статически на
`document_start`, поэтому применяется до первой отрисовки и переживает любые
перерисовки React'а.

Выключить статически объявленный стиль нельзя, поэтому правило написано через
`html:not(.mnk-off)`. `content.js` читает состояние из `storage.local` и вешает
класс `mnk-off` на `<html>`, когда расширение выключено, а также слушает
изменения хранилища — отсюда мгновенное переключение в открытых вкладках.

## Если оверлей вернулся

Значит, на сайте поменялась разметка. Посмотри в DevTools актуальный класс-лист
элемента и поправь селектор в `hide.css`.
